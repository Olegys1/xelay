# Общие новости университета: подключение

## Что изменилось

- Поля профиля **«Навички»**, **«Можу допомогти з»**, **«Хочу дізнатися»** стали обычными текстовыми полями. Запятые, пробелы и переносы строк сохраняются. Старые ответы остаются доступными, отдельный SQL для профиля не нужен.
- Новости уже выбирались по университету и факультету из профиля. Эта привязка сохраняется.
- Внутри существующего раздела **«Новини»** теперь два направления: **«Новини факультету»** и **«Загальні новини КНУ»**. Для другого университета используется соответствующее название общего потока. В боковом меню нового пункта нет.
- В обоих потоках есть классификация **«Усі»**, **«Новина»**, **«Подія»**, **«Можливість»**, **«Оголошення»**, фотографии и ссылки, предложения новостей, модерация, редактирование и удаление.

## Что вставить в Supabase

1. Открой рабочий проект **Xelay mvp** в Supabase.
2. Слева открой **SQL Editor** → **New query**.
3. В проекте открой файл **`supabase/migrations/202610020001_university_news_scopes.sql`**.
4. Скопируй **всё содержимое** файла, включая `begin;` и `commit;`.
5. Вставь в SQL Editor и нажми **Run**. Дождись завершения без ошибки.
6. Закоммить и запушь изменения проекта. Дождись **Ready** в Vercel у проекта с рабочим доменом **www.xelay.ink**.
7. Обнови сайт. После одобрения нового редакторского доступа обнови страницу или войди заново, чтобы загрузились права.

Эта миграция применяется после уже существующих:

- `202609280001_universities_news_admin.sql`
- `202609280002_message_interactions.sql`
- `202609300002_news_media_links.sql`
- `202609300003_news_management.sql`

Если эти миграции уже выполнялись, повторять их не нужно. Новые переменные окружения, ключи или DNS-записи для этой функции не нужны. SQL на рабочей базе автоматически не выполнялся.

## Как выдавать доступ

1. Участник выбирает нужную вкладку внутри **«Новини»** и нажимает **«Доступ до загальних новин»** или **«Доступ до новин факультету»**.
2. Заявка относится только к выбранному направлению. Можно отдельно подать заявку на новости факультета и на общие новости университета.
3. Администратор открывает **«Адмінпанель»** → **«Заявки на редакторський доступ»**.
4. Заявки разделены на вкладки **«Новини факультетів»** и **«Загальні новини»**.
5. Нажатие на аватар или имя заявителя открывает его публичный профиль. В заявке также указан вуз и направление доступа.
6. Нажми **«Прийняти»** или **«Відхилити»**.

Редактор факультета управляет только новостями своего факультета. Редактор общих новостей управляет только общими новостями своего университета. Один человек может получить оба доступа через две заявки. Администраторы имеют доступ к обоим направлениям всех университетов.

## Существующие данные

Старые новости и факультетские редакторы сохраняются. Общие новости хранятся в тех же таблицах новостей, с указанным университетом и без факультета. Старым редакторам факультетов общий доступ автоматически не выдаётся.
