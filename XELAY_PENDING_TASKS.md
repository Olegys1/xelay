# Отложенные задачи Xelay

## Почтовые уведомления — вернуться после семинаров

Дата фиксации: 1 октября 2026 года. Пользователь попросил отложить исправление.

- Подтверждение регистрации и восстановление пароля через Supabase SMTP работают; письмо регистрации попадало в спам.
- Почтовые уведомления платформы пока не отправляются: очередь `notification_email_outbox` остаётся `pending` с `attempts = 0`; обработчик отвечает HTTP 503 «Надсилання сповіщень ще не налаштовано.».
- Локально исправлены импорты обработчиков (`notificationEmail.js`) и добавлена безопасная диагностика `configuration_errors` после авторизации. Значения секретов не выводятся.
- Во встроенном браузере были открыты переменные старого проекта Vercel `xelaycompany-glitch/xelay-knowledge-exchange`, у которого домен `xelay-knowledge-exchange.vercel.app`. Текущий репозиторий — `Olegys1/xelay`; рабочий сайт — `https://www.xelay.ink`. Нужно найти соответствующий проект/аккаунт (раньше в контексте была команда `ehouts-projects`) и подтвердить опубликованную версию.
- Для актуального обработчика 503 без `configuration_errors` указывает на отсутствующий/невалидный `NOTIFICATION_WEBHOOK_SECRET`. Сначала подтвердить версию deployment; не менять ключи наугад.
- Проверить настройки сервера, совпадение секрета с Vault и webhook, затем отправку нового уведомления и ответ Resend. Отдельно разобраться с доставляемостью регистрационных писем.
- Не просить пользователя раскрывать API-ключи, service_role, SMTP-пароль или webhook secret. Публичные ожидаемые настройки: `NOTIFICATION_EMAIL_ENABLED=true`, `XELAY_PUBLIC_URL=https://www.xelay.ink`, `XELAY_EMAIL_FROM=Xelay <notifications@xelay.ink>`.

Это запись для продолжения работы, а не подтверждение устранения проблемы.
